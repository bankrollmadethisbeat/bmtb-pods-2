Advanced FiveM props/pods system for immersive server interactions.

Modern AirPods-style music player with live volume control, theme customization, and framework/inventory auto-detection.

## Features

- Modern Figma-based interface
- Dynamic theme color customization
- Live volume updates while playing
- Movement while UI is open
- Shift-based fine volume control
- ESX / QBCore / QS inventory auto-register
